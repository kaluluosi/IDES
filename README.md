# IDES

rust native memory ai agent harness / RUST原生记忆AI智能体底座

## 本站（GitHub Pages / mkdocs）

本站是 IDES 的对外站点仓库，基于 **mkdocs**：

- **首页**：`docs/index.html` — 终端风官网单页（原样静态托管）
- **文档**：`docs/*.md` — mkdocs 渲染的文档页（随内容逐步补充）

### 本地开发

```bash
uv run mkdocs serve     # 本地预览 http://127.0.0.1:8000
uv run mkdocs build     # 构建到 site/
```

> 素材源头：`H:\projects\IDES`（官网设计稿 terminal.css / terminal.js / index.html）
